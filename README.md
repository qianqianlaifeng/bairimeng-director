### 📸 把搭好的场景出图（截图 / 机位组图）

导演台底栏两个按钮：

| 按钮 | 出什么 |
|---|---|
| **📷 截图** | 当前画面存成 PNG。2D 平面模式下出**平面图**（会临时清掉选中框，拍完还原）；3D 立体模式下出**站位图**，并且会把人物名牌按标签层位置**画进图里**（画布本身不含 DOM 名牌），拿到手就是一张能直接对位的图 |

### 🏗 场景库：打开已有场景改

场景库卡片上现在有两个入口进同一套景：**点缩略图**（hover 出现「✏️ 打开编辑」）或点**「✏️ 打开编辑」**按钮。

- 顶部提示会变成「正在编辑场景库「××」」，主按钮变成 **「💾 保存到场景库」**
- 保存是**原地覆盖那一条**（不会再冒出一个「场景 2」），名字沿用原来的（要改名用卡片上的「重命名」）
- **已经套用这套景的镜头不会被改动** —— 各镜存的是自己的副本，想同步新版就再点一次「套用到镜头」
- 卡片上的「用在 N 镜」就是当前引用数，删场景前可以先看清有多少镜在用它

### 🖼 导入环境图（看图 → 3D 场景）

入口两处：**场景库 → 🖼 导入环境图**，或导演台底栏 **🖼 环境图**。拖图 / 选文件 / 直接 Ctrl+V 粘截图都行。

| 模式 | 需要什么 | 出什么 |
|---|---|---|
| 🤖 **AI 视觉反推** | 设置 → AI 接口里配一个**支持图片**的模型（gpt-4o / glm-4v / qwen-vl 等） | 房间尺寸、家具种类与位置、每个人物的站位与朝向、光源色温与高度、以及**还原这张参考图自己的视角**的机位；写「坐下」的人会真的吸附到座位面上 |
| 🎨 **本地起手** | 什么都不用配，不联网 | 照图取色（地面 / 墙主色）、把图里的亮区变成 2~3 个光源（暖冷按色相判）、给一个 8×6m 的空景让你直接往里摆家具 |

「自动」= 有 AI 用 AI，没 AI 自动退到本地，失败也会退回并告诉你原因。

**只注入草稿，不自动落库**：应用到导演台后你先看 2D/3D，满意再点「保存到镜头 / 存入场景库」。

### 推荐 AI 出片工作流

1. **项目台**建项目（短剧选 9:16）
2. **剧本**页贴入剧本 → 「⚡ 一键拆分镜」→ 确认导入
3. **运镜词典**里逐镜挑运镜（看不明白就点「详解」看白模演示）
4. **运镜预演**检查关键镜头的实际效果
5. **动态分镜**整片连播，检查节奏和时长（短剧单集 60~90 秒）
6. **提示词工坊**全部生成 → 全部复制 → 粘到 AI 视频工具逐镜出片
7. 出片后回**审核台**打分，不满意的镜头打回重拍

### 📥 分镜导入（把同学写的分镜表导进来）

进「分镜板」→ 右上角 **📥 导入分镜**。三种用法：

| 用法 | 做法 |
|---|---|
| 粘贴 | 把 Excel / 飞书 / 石墨里的表格整段复制，粘进文本框，实时显示「解析到 N 镜」和前 8 镜预览 |
| 选文件 | 「📄 选文件」挑 `.csv / .tsv / .txt / .md / .json`；Excel 存的中文 CSV 是 GBK 编码，会自动兜底不乱码 |
| 发模板 | 「⬇ 下载模板 CSV」把带表头的空表发给同学，他们填好回传给你导进来 |

**能认的格式**：CSV（逗号）、TSV（制表符）、Markdown 表格（`| --- |`）、每行一条的纯文本、JSON 数组。

**表头（可选）**：认这些名字，顺序随便放，写了哪个用哪个：

`镜号` `画面描述` `台词` `时长` `景别` `运镜` `角度` `场次` `备注`
（英文也行：`no / shot / dialogue / duration / size / camera / angle / scene / note`）

**没写表头**就按 `镜号 · 画面 · 台词 · 时长` 的顺序猜；`1. 推门进来 3s` 这种带编号的纯文本也能认。

**景别 / 运镜 / 角度**留空会自动推断：写「远景 / 全景 / 中景 / 近景 / 特写」→ 对应景别；写「固定 / 缓推 / 拉远 / 横摇 / 跟拍」→ 对应运镜；写「平视 / 俯拍 / 仰拍 / 过肩 / 鸟瞰」→ 对应角度。没在描述里写就留空，不会瞎猜。写英文也行（`CU` / `MS` / `slowPush`）。

**列会自动对位**：同学手写的表经常某行少一列（最常见是漏了空的「台词」列）。导入会按每一列「长得像什么」自动对位——时长是数字、景别运镜是关键词、画面是文字，不会把「2」这种时长塞进台词里。

**追加 vs 替换**：默认「追加到现有分镜」；切到「替换」时弹窗里会直接写清「会清空现有 N 个镜头」，按钮变成红色的「清空并导入」，不会出现浏览器原生确认框。

**导出再导入**：「📤 导出」把当前分镜板存成 CSV（和导入同一套表头、中文景别运镜名），发给同学在 Excel 里改完再「📥 导入」回来即可，形成协作闭环。

| 操作 | 说明 |

### 🪑 让人坐下去（座位系统）

以前把姿势改成「坐下」，人只会原地屈腿站在地上。现在座位是**真的**：

| 想做什么 | 怎么做 |
|---|---|
| 让人坐上椅子 | **右键椅子/沙发/长凳/床 → 🪑 请人坐下**（自动挑离他最近的空座位） |
| 让人自己找座位 | 选中人物 → 右侧面板「坐到最近的座位」，或右键人物 → 同一条目 |
| 最直观的做法 | **把人物直接拖到椅子上松手** —— 落座；再把他拖离椅子 —— 自动起身 |
| 起身 | 人物面板「起身」，或右键人物 → 起身 |

坐下去之后会发生什么：

- 位置、朝向、坐面高度都由**这个座位**算出来（椅子面朝哪，人就朝哪；坐面 48cm 人就抬到 48cm）
- **挪椅子/转椅子/缩放椅子，坐着的人跟着走**，不会留在原地
- **删掉椅子，坐着的人自动起身**（Ctrl+Z 撤销后椅子回来，人还在座位上）
- 坐着的人**不再被算成"和家具穿模"**，点「自动摆好」也不会把他从椅子上推开
- 沙发/长凳/床有**多个座位**，两个人不会叠在同一个位置
- 3D 立体布景、运镜预演、动态分镜、导出 mp4 都会带上坐面高度；俯视图里坐着的人脚下有一圈虚线座标
- AI 搭景如果写了「坐下」，落地时也会真的吸附到座位面上

可坐的家具：椅子、办公椅、沙发（2 座）、长凳（2 座）、床（2 座）。

### 台词配速体检

卡片上如果出现黄色「⏱ 台词 X.Xs > 镜头 X.Xs」，表示按中文 5 字/秒的速度这段台词在这镜里念不完——要么把镜头时长加上去，要么删台词。悬停可看提示。

### AI 接口（可选）

「设置 → AI 接口」填入任意 OpenAI 兼容接口（`/v1` 地址 + 模型名 + API Key）即可解锁：

- 🤖 **AI 拆分镜**：按剧情节奏智能分镜
- ✨ **AI 增强提示词**：把一句话画面描述改写成专业提示词

密钥只存在本机浏览器，随请求直接发给你填的接口，本站无任何中间层。

## 🛠️ 技术

- 纯原生 HTML/CSS/JS（ES Modules），**零依赖、零构建**，静态托管直接跑
- 自研 Canvas 3D 白模渲染引擎（透视投影 + 画家算法 + 平面光照 + 雾），驱动运镜预演/词典演示/动态分镜
- localStorage（结构化数据）+ IndexedDB（参考图 Blob）
- Service Worker 离线缓存 + PWA Manifest
