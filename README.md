# 🎬 白日梦导演台

> 把脑中的白日梦，拍成一部真片子 —— 纯前端 AI 影片导演工作台
>
> 剧本 → 拆分镜 → 运镜预演 → 动态分镜 → 时间线剪辑 → 提示词 → 拉片审核，一站式完成 AI 短片前期制作。

> **版本（2026-10-28 · v1.12.0）**：**AI 搭景** —— 配好 AI 接口后，按当前镜头的描述（含台词、场次、前后镜、同场已有布局）自动生成 房间 / 家具 / 光源 + **人物走位** + **机位**，本地校验夹取、空场景自动返修，注入导演台当草稿（逐镜确认后再保存）；**动态分镜可「🎬 导出 mp4」**（WebCodecs 逐帧编码 1280×720@24fps、无音轨），顺手修好 mp4 封装器三处结构错误（此前 WebCodecs 出的 mp4 打不开）。

## 🚀 使用

直接打开线上地址即可使用，无需注册、无需安装：

**https://qianqianlaifeng.github.io/bairimeng-director/**

- 所有数据只存在你的浏览器（localStorage + IndexedDB），**不上传任何服务器**
- 支持离线使用（PWA + Service Worker）
- 换设备前记得在「设置 → 数据管理」导出备份

### 🏗 场景搭建怎么用（v1.1 重做）

进「分镜板 → 某一镜 → 🏗 场景搭建」，全屏导演台打开：

| 操作 | 做法 |
|---|---|
| 画空间 | 左栏「画房间 / 画墙 / 造物 / 打洞 / 人物」，或画布左侧浮动工具栏 |
| **删东西** | **右键点物体 → 删除**（也可 Del / 右侧属性面板的垃圾桶 / 场景清单的 ✕） |
| 移动 | 选中后直接拖；方向键微调 0.5 格，Shift+方向键 0.1 格 |
| 多选 | 空白处拖动框选；Shift+点击加选；Ctrl+A 全选 |
| 复制 | 右键「复制」或 Ctrl+D（原地再来一个） |
| 改名 | 双击物体，或右键「重命名」，或 F2 |
| 平移画布 | 右键拖动 / 空格+拖动 / 中键拖动 |
| 放家具 | 右侧「物件库」点一个（桌子/沙发/床/柜…），画布点一下落地，连着点连着放，Esc 退出 |
| 撤销 | Ctrl+Z / Ctrl+Shift+Z（只记真正的改动，不会把「点一下选中」也记进去） |
| 找机位 | 右上「立起来」进 3D：左拖转、滚轮缩放、右键平移、双击聚焦；底部 俯视/斜视/正视 |
| 存场景 | 右下「💾 保存到镜头」——同时存白模场景（给运镜预演用）和导演台原生场景（再打开房间还是房间） |

### 推荐 AI 出片工作流

1. **项目台**建项目（短剧选 9:16）
2. **剧本**页贴入剧本 → 「⚡ 一键拆分镜」→ 确认导入
3. **运镜词典**里逐镜挑运镜（看不明白就点「详解」看白模演示）
4. **运镜预演**检查关键镜头的实际效果
5. **动态分镜**整片连播，检查节奏和时长（短剧单集 60~90 秒）
6. **提示词工坊**全部生成 → 全部复制 → 粘到 AI 视频工具逐镜出片
7. 出片后回**审核台**打分，不满意的镜头打回重拍

### AI 接口（可选）

「设置 → AI 接口」填入任意 OpenAI 兼容接口（`/v1` 地址 + 模型名 + API Key）即可解锁：

- 🤖 **AI 拆分镜**：按剧情节奏智能分镜
- ✨ **AI 增强提示词**：把一句话画面描述改写成专业提示词

密钥只存在本机浏览器，随请求直接发给你填的接口，本站无任何中间层。

## 🛠️ 技术

- 纯原生 HTML/CSS/JS（ES Modules），**零依赖、零构建**，静态托管直接跑
- 自研 Canvas 3D 白模渲染引擎（透视投影 + 画家算法 + 平面光照 + 雾），驱动运镜预演/词典演示/动态分镜
- localStorage（结构化数据）+ IndexedDB（参考图 Blob）
- Service Worker 离线缓存 + PWA Manifest

```bash
# 本地运行：任意静态服务器
npx serve .
# 或
python -m http.server 8080
```
