01这是什么？能帮我做什么

你给一段剧本、剧情或视频提示词（也可以加几张角色 / 场景参考图），网站帮你把「开拍前该想清楚的事」一次做完：

输入一段文字，或文字 + 角色 / 场景 / 道具图片
产出分镜卡、3D 白模场景与机位、宫格故事板、逐镜生图与视频提示词

最后把提示词复制到即梦、可灵、海螺、Vidu 等 AI 视频工具出片，回来在「审核台」打分、打回重拍。

💡 网站是纯前端，没有服务器、不上传你的剧本和图片；所有东西只存在你这台电脑的浏览器里。不配任何 AI 接口、不联网，核心功能也照样跑。

网站里左下角「❓ 新手教程」是同一份说明书的站内版：六个分组、35 页，点目录直接跳、键盘 ← → 翻页，卡片上还有「➜ 带我去…」一键跳到对应功能。

035 分钟跑通第一单（第一次就走这条）

别一上来研究几十个按钮，照这五步点一遍，你就有一张能发给客户的故事板。

1
建项目：左边「🏠 项目台」→ 新建项目 → 选画幅。短剧选 9:16，长视频选 16:9，社交贴图选 1:1。
2
填样例：左边「🤖 AI 导演台」→ 点「📝 填个示例」，先用人家的样例试。
3
一键开拍：什么都不用改，直接点「⚡ 一键开拍」。进度条会走五步：去噪 → 拆镜 → 配运镜 → 搭景 → 算宫格。
4
看结果：每镜都有画面、景别、角度、运镜、空间关系、动作情绪；场景和机位也自动搭好。
5
出图：点「🎛 宫格故事板」→「📥 下载 PNG」。想改成 AI 画的图，见第 7 节。
💡 跑通一遍之后，把示例换成你自己的剧本即可。默认「追加」到现有分镜，不会覆盖你已做好的镜头；想清空重来才勾「替换现有分镜」。

04AI 导演台详解

4.1 页面上每个开关管什么

控件作用
大文本框贴剧本 / 剧情 / 视频提示词；「📝 填个示例」一键填样例
导演额外要求可空。例「冷色调，多用特写，节奏慢一点」
AI 智能拆镜不勾＝本地规则、完全不联网；勾上＝用你在设置里配的大模型
自动搭建场景 + 机位把每镜变成 3D 场景和摄影机位置，建议一直勾
替换现有分镜默认不勾＝追加；勾了会清空旧镜头，别手滑
完成后自动弹出宫格故事板不想要自动弹就取消勾选

4.2 提示词怎么写才拆得准

写「谁 · 在哪 · 做什么 · 什么情绪」就行，不用会专业术语，一行一个动作最容易拆准。

好例子 深夜便利店，店员小林趴在柜台上打瞌睡。自动门叮地开了，一个浑身湿透的女孩走进来，径直走向冰柜拿出一罐冰可乐。小林抬头：外面下雨了吗？女孩没回答，把可乐贴在脸上。
  • 换场次另起一行写「【第二场 天台】」，会自动多分一镜。
  • 台词单独写一行，或用「小林：……」，会自动归到那一镜。
  • 带时间码的 H3 / 短视频提示词（如 [0.0-2.0]）也能整段贴进来拆。
  • 只写「赛博朋克、电影感、4K」这种风格词拆不出镜头 —— 它会被当成全片设定收起来。

4.3 自动去掉「拍不出来」的信息

从别处复制来的视频提示词常夹着跟画面无关的东西，开拍第一步就把它们剥出来，只留能拍的动作：

  • 会被剥掉：风格锁、负向词、音轨 / 配乐、分辨率帧率、水印要求、平台参数。
  • 剥掉不是丢掉：风格 / 负向 / 音轨收进全片设定，写生图提示词时自动带上。
  • 进度条会写明「去掉 N 条噪声」。以前 51 个镜头全是「中景·固定·3s」就是没去噪导致的。

4.4 上传资产图，让故事板照着你的图来

  1. 页面中间虚线框：把图片拖进去、点框选文件，或直接 Ctrl+V 粘截图，支持一次多张。
  2. 起个一眼能认的名字，例「女主_红风衣」「老便利店_内景」「道具_铜钥匙」。
  3. 点「🔍 让 AI 看懂这些图」：配了视觉模型会读外观和配色；没配也能按文件名认出角色 / 场景 / 道具。
  4. 再点「⚡ 一键开拍」，故事板和生图提示词都会带上这些资产的外观描述。
💡 图片默认只在你本机；只有你配了支持看图的接口、并主动点「让 AI 看懂」，才会把图发出去。

4.5 自动配运镜、搭场景、定宫格数

  • 运镜景别：情绪爆点给特写、对话给中景或过肩、出场给大远景、追逐给跟拍、对峙给缓推，结果表逐镜可改。
  • 搭景：按画面描述挑房间家具、按点名的角色摆人，写「坐在沙发上」就真落到沙发面上；机位按景别定远近、角度定高低、运镜给起幅落幅。
  • 宫格数：剧情被切成若干「节拍」，节拍越多宫格越大：1×4 → 2×3 → 3×3 → 4×3 → 4×4；镜头多过一页自动分页。
  • 每格写清三件事：空间关系（谁左谁右、前后层次、朝向）、机位角度（景别 / 角度 / 运镜）、人物动作情绪。

4.6 要不要配大模型接口

不配也能用，而且默认就是这么用的。拆镜、去噪、配运镜、搭景、算宫格、出故事板全走本地规则，零联网。

想让拆镜 / 看图更聪明：「⚙️ 设置 → 🤖 AI 接口」填任意 OpenAI 兼容地址（/v1 结尾）+ 模型名 + 密钥；看图还需要模型支持图片（gpt-4o / glm-4v / qwen-vl 这类）。接口失败、超时、跨域被挡都会自动退回本地规则并说明原因，不会卡住。密钥只发给你填的那个地址，本站没有中间层。

05手动精修流程（想一镜镜抠就用这条）

AI 一条龙和手动精修不是二选一，AI 生成的每一镜都能手动改，改完再回去出图。

步骤页面做什么
1🏠 项目台建项目、选画幅；多项目互不干扰
2📜 剧本贴剧本 →「⚡ 一键拆分镜」按场次 / 段落切镜；配了接口可「🤖 AI 拆分镜」
3🎞️ 分镜板改画面描述、换景别角度运镜、拖卡片排序、挂参考图；「傻瓜模式」四问出分镜；「📥 导入分镜」认 CSV / TSV / Markdown / JSON；「☑ 批量」改多个镜头
4🧭 运镜词典37 种电影运镜，每种有白模动画演示 + 成品提示词，点「用到此镜头」一步到位
5👁️ 运镜预演 / 🌟 动态分镜单镜白模预演；整片连播带台词字幕转场，可导出 mp4 当审片样片
6🎚️ 剪辑台 / 🪄 提示词工坊时间线粗剪、调时长转场；生成场景 / 镜头 / 光线 / 风格四段式提示词，一键复制去出片
7🔍 审核台构图 / 运镜 / 光线 / 表演 / 音画五维打分，写意见，一键打回重拍
💡 卡片上出现黄色「⏱ 台词 X.Xs > 镜头 X.Xs」表示这段台词念不完，加时长或删词。短剧单集建议 60~90 秒。

06场景 · 道具 · 机位

6.1 一键搭景与 3D 导演台

  • 分镜板右上角「🎬 一键搭景」：按每张卡的景别 / 角度 / 运镜，把没搭景的镜头一次性变成 3D 场景 + 机位；已搭过的默认不动，60 秒内可一键撤销。
  • 「分镜板 / 场景库 → 新建场景」进全屏导演台：左边画房间、画墙、放道具、放人物；右键任何东西出菜单（隐藏 / 删除 / 复制 / 请人坐下）。
  • 相机：左拖转视角、滚轮缩放、右键或空格+拖平移、双击回全景；挡画面点底栏「▦ 隐藏界面」。
  • 搭完先「📚 存入场景库」，这是唯一不会丢的保险；「💾 保存到镜头」只进这一镜。

6.2 91 种道具怎么找、怎么放

右侧「物件库」有 91 种道具，分家具 / 厨卫 / 电器 / 灯饰 / 装饰 / 建筑 / 办公商业 / 户外交通 / 片场器材九类。

  1. 先选上面的分类，或搜索框打「沙发」「路灯」立即筛出来。
  2. 点一个道具 → 到画布点一下落地；连着点连续放，按 Esc 退出放置。
  3. 选中后 Del 删除、方向键微调；清单里可 🔒 锁定防误拖；顶部「＋」可建自定义分组。

6.3 人物 / 坐下 / 环境图

  • 选中人物改体型（标准 / 瘦 / 胖 / 小孩）、整体大小 0.3–3×、四肢关节；3D 里能直接点着胳膊腿拖。
  • 右键椅子 / 沙发 →「🪑 请人坐下」，或直接把人拖到椅子上；挪椅子人跟着走，删椅子自动起身。
  • 「🖼 环境图」导入照片：2:1 全景铺成环境球，普通画幅立成背景板；配了视觉模型可反推房间尺寸 / 家具 / 光位，没配也能本地取色起手。

6.4 「拍头却拍到身体」自查（此 BUG 已修复）

⚠️ 旧版本里搭过 3D 景的镜头被强制成自由机位、取景目标写死 1.15m（腰），所以特写会怼到身上。新版已修：目标点随机位一起保存，特写 / 近景自动对准脸部，小孩和坐姿会自动跟着降。
  1. 先看这一镜的景别：想拍脸就选「特写 / 近景」，别用中景。
  2. 还不对：镜头编辑里调「看向高度」（脸约 1.6m、胸约 1.3m、腰约 1.15m）和「机位高度」，现在真的生效。
  3. 人物是小孩或坐着：勾「跟随人物」，镜头按身高自动构图。
  4. 开着右下角「监看器」小窗调，主画面随便转都不丢构图；改完到预演或宫格图看一眼实际画面。

07故事板与 AI 生图

7.1 宫格故事板

分镜板右上角「🎛 宫格图」（AI 导演台结果页也有同一个按钮）：每镜自己出一格，优先用这一镜搭好的 3D 场景按景别 / 角度 / 运镜离屏渲静帧，没搭景的会落成占位格并写明原因。

  • 版式 1×4 / 2×3 / 3×3 / 4×3 / 4×4 任选，「自动」按镜头数挑。
  • 格子下方自动带镜号 · 景别 · 角度 · 运镜 · 时长 · 台词；AI 导演台出的格子还会带空间关系和动作；画面上按运镜画推 / 拉 / 移 / 摇 / 绕箭头。
  • 「📥 下载 PNG」直接交付。

7.2 生图接口怎么配（含免费无密钥）

「⚙️ 设置 → 🎨 生图接口」填一次，AI 导演台和宫格故事板就能逐格出图。两种类型选一个：

类型填什么适合
OpenAI 兼容 /images/generations地址填到 /v1 + 模型名 + 密钥；可设尺寸、返回格式、额外参数 JSON有自己的中转 / 付费接口
URL 直出（GET）带 {prompt} 占位的地址；点「🆓 一键填免费接口」自动填好 Pollinations，可免密钥想零成本先试试

尺寸按画幅选：横屏 1344x768、竖屏 768x1344、方形 1024x1024。点「🖼 测试画一张」验证，没问题再「保存」。

💡 接口要允许跨域、返回 b64_json 或图片 url。密钥只发给你填的地址，本站没有中间层。

7.3 逐格生图 / 回填 / 提示词包

  1. AI 导演台结果页「🎨 AI 逐格生图」，或宫格弹窗「🤖 AI 逐格生图」：一格调一次接口，出完自动回填对应镜号，可中途「⏹ 停止」。
  2. 某张不满意：单独改那一镜的描述再重出，不用整板重来。回填后再开一次宫格图就是 AI 画的故事板。
  3. 不想在站里配接口：点「🧾 生图提示词包」下载 txt，一条提示词＝一个格子（含画幅 / 人物一致性 / 风格锁 / 负向锁），拿去任意生图工具逐张画，再「🖼 逐格回填」按镜号塞回来。
⚠️ 别让 AI 一次画整张九宫格：格子整体比例模型对不上，格里的字必崩，也没法单格重抽。逐格出图 + 本地拼格才是稳的做法。

08数据存在哪？怎么备份

项目和图片都只存在这台设备的浏览器里（localStorage + IndexedDB）。同一个网址 + 同一台电脑 + 同一个浏览器下次打开还在；换浏览器、换电脑、清了浏览器数据就找不回来了。

要做什么点哪里
换设备 / 换网址搬家旧版「设置 → 数据管理 → 📦 导出全部备份」→ 新版「📥 导入备份」
只交付一个项目右上角「📦 导出项目」
交付图片宫格图「📥 下载 PNG」、导演台「📷 截图 / 🎞 机位组图」
⚠️ 收工前记得导出备份。线上版与本地启动版数据不互通，网址不同就要导出再导入。
